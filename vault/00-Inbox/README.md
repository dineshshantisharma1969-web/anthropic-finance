# 📥 Inbox

Paste anything raw here and I'll sort it into the right lifecycle folder:

- **A GST / IT notice** → paste the text (or drop the PDF in `_attachments/`). I'll create a
  dated note in `30-Notices/` and pull the relevant law + rules to draft a reply.
- **A statutory section / circular** → I'll create a verbatim note in `10-Law/…`.
- **A stray finding / number** → I'll turn it into a `40-Workings/` note or fold it into an
  existing one.

No need to format it — just capture it. One item per capture is ideal, but a dump is fine; I'll
atomize it.
