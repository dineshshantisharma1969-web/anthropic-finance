## Can we legally put the GST Act in our wiki?

**Yes.** The CGST Act is an Act of Parliament. Under **Section 52(1)(q) of the
Copyright Act, 1957**, reproduction of any Act of a legislature (and rules/orders
made under it) does **not** infringe copyright. The same applies to the IGST Act,
State GST Acts, GST Rules, notifications and circulars. The only condition to be
mindful of: if you reproduce an Act *together with your own commentary*, the
commentary is your content, but the Act text remains freely reproducible.

**The practical caveat is currency, not copyright.** The GST law is amended every
year (Finance Acts) and continuously via notifications. A verbatim copy pasted
into a wiki silently goes stale. So this section follows the approach:

> **Index + summaries + business-specific guidance here; always verify exact
> wording against the official sources below before relying on it in a reply to
> a notice or a filing.**

## Official sources (always authoritative)

- **CBIC GST portal (Acts, Rules, Notifications, Circulars):** https://www.cbic.gov.in/entities/gst
- **CBIC Tax Information Portal (consolidated, amended text):** https://taxinformation.cbic.gov.in
- **GST Council:** https://gstcouncil.gov.in
- **India Code (official Act text):** https://www.indiacode.nic.in
- **GST common portal (returns, notices, ledgers):** https://www.gst.gov.in

## How to copy these pages into the GitHub Wiki

GitHub Wikis are a separate mini-repository. Two ways:

1. **Paste:** open the Wiki → *New Page* → name it (e.g. `GST Act — Section Index`) →
   paste the markdown from the matching file here.
2. **Clone the wiki repo** (`https://github.com/<owner>/<repo>.wiki.git`), copy these
   `.md` files in (filename = page title), commit and push.

Keep the copy in `docs/wiki/gst-act/` in the main repo as the source of truth and
re-paste after edits, so wiki and repo never diverge.
