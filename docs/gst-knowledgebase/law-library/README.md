# Law Library — how to populate

**Rule: only official documents.** Download from cbic-gst.gov.in ("GST Law" section
has consolidated as-amended Acts/Rules, plus notification & circular archives),
gstcouncil.gov.in, gst.gov.in. Store the PDFs in a Google Drive folder named
**"GST LAW LIBRARY"** (mirroring the salary-brain pattern), then register each file
in the matching INDEX.md here with its Drive ID and as-amended date.

Load order: 1) CGST Act  2) IGST Act  3) CGST Rules  4) rate notifications
(1/2017-CT(R) services + 11/2017-CT(R) goods lines relevant to you)  5) non-rate
notifications for current FY  6) circulars on your recurring issues.

For a manpower-services company the high-priority topics are: S.7/supply, S.9(3)
RCM list, S.15 valuation (pure-agent question on salary reimbursements!), S.16-17
ITC, S.22-25 registration (multi-state), TDS u/s 51 (government clients), e-invoicing
thresholds, GSTR-7 credits.
